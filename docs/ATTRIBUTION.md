# Attribution and reuse policy

We implement **ideas that are already published**. We do not copy source trees.

## Papers and tools

- He, Yang, Burckhardt, Kapravelos, Vasilescu, Kästner. *Six Million (Suspected) Fake Stars on GitHub*. ICSE 2026. Detector: https://github.com/hehao98/StarScout
- Astronomer (MIT) — https://github.com/Ullaakut/astronomer
- Public writeups and CLIs in the same genre (StarGuard, fake-star-detector, GitProbe, Fortune, shotstars). Read their licenses before copying *code*. This repo's code is original.

## GitHub terms (commercial intent)

GitHub Acceptable Use + API terms (paraphrased for operators of this tool):

- Do not sell personal information collected from GitHub.
- Researchers may use public non-personal information if resulting publications are open access.
- API abuse and token sharing can get the app or account suspended.

Practical rule for this project: persist **repo-level derived scores**. If a future hosted API exists, charge for *compute and the verdict*, not for a dump of users.
